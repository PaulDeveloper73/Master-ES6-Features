INVOICE MANAGEMENT DASHBOARD
============================

FILES
-----
financial-records-styled.html  Dashboard markup and external library links
style-dompro.css               Custom design and responsive styling
mydomPro.js                    Search, filtering, sorting, calculations, and exports
invoices.js                    Central invoice data array

RUN LOCALLY
-----------
1. Keep all four project files in the same folder.
2. Open the folder in VS Code.
3. Start a local HTTP server (for example, VS Code Live Server).
4. Open financial-records-styled.html through that server.

The JavaScript uses ES modules, so opening the HTML directly with file:// may be blocked
by the browser. Tailwind, Lucide, SheetJS, and jsPDF are loaded from CDNs and need an
internet connection for their corresponding functionality.

FILTERS AND SORTING
-------------------
- Use global search across all invoice data.
- Filter by global status or year.
- Choose inclusive Date from / Date to limits using invoice createdAt values.
- Use the filter row under the table headings for column-specific filters.
- Click each column heading to sort ascending; click it again to switch to descending.
- Reset all filters and sorting with the reset button.

EXPORTS
-------
- CSV: comma-separated file with UTF-8 BOM.
- Excel: real .xlsx workbook using SheetJS.
- PDF: generated PDF table using jsPDF and AutoTable.
- Word DOCX: genuine .docx document generated with the docx library.
- Word DOC: Word-compatible HTML document using the older .doc extension.
- JSON: invoice objects serialized as formatted JSON.
- TXT: readable plain-text table.

Every export uses the currently filtered and sorted records. Excel and PDF exports use
CDN libraries. CSV, Word-compatible DOC, JSON, and TXT are generated by the browser.

DATA
----
Edit invoices.js to change or add records. Each invoice should include:
id, customerId, customerName, amount, status, year, createdAt (YYYY-MM-DD).
