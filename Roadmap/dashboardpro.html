PHASE 1

JavaScript Masterclass

Month 1 (Weeks 1–4)

This month represents your core technical foundation. Do not rush through Month 1. Frameworks such as React, Next.js, Node.js, and React Native will become significantly easier to engineer if your core JavaScript understanding is bulletproof.

Week 1: Fundamentals

Syntax & Logic
  • Core JavaScript syntax, runtime mechanics, and dynamic typing.
  • Variable scopes: let vs const scoping rules.
  • Data primitive types: Strings, Numbers, Booleans, null, undefined.
  • Complex primitive containers: Objects and Arrays fundamentals.
  • Operators: Arithmetic, Comparison, Strict Equality, Logical Operators.
  • Control Flow: if/else, switch statements, and Ternary operator conditional logic.
Practical Target Builds:

Build isolated CLI/GUI tools: Age calculator, Grade calculator, Simple calculator, Currency converter, and Salary calculator.

Week 2: Functions, Arrays & Objects

Data Structures
  • Function Declarations vs Arrow Functions (const greet = () => {}).
  • Parameters, Arguments, Return values, Default Parameters, Scope.
  • Callback functions and Higher-Order Function mechanics.
  • Nested Objects, Array Destructuring, Object Destructuring.
  • Spread operator (...) and Rest parameters.
  • Master vital Array methods: map(), filter(), reduce(), find(), findIndex(), some(), every(), forEach(), sort().
// Array Transformation Example
const pendingTotal = invoices
  .filter(inv => inv.status === 'unpaid')
  .reduce((acc, inv) => acc + inv.amount, 0);

Week 3: Modern JS & Asynchronous Architecture

Async Patterns
  • Template Literals, ES Modules (import / export).
  • OOP in JS: Classes, Constructors, this context, Static methods, Getters/Setters.
  • Error Handling: try / catch / finally blocks.
  • Asynchronous Evolution: Callbacks → Promises → async / await.
  • Promise methods: then(), catch(), finally().
  • Asynchronous Fetch API consumption and HTTP error handling.
// Async Fetch Pattern
async function loadData(url) {
  try {
    const res = await fetch(url);
    if (!res.ok) throw new Error(res.statusText);
    return await res.json();
  } catch (err) { console.error(err); }
}

Week 4: Advanced Concepts & DOM Storage

Browser Execution
  • Execution Context, Variable Hoisting, Lexical Scope, Closures.
  • Browser Execution Engine: Call Stack, Event Loop, Microtasks, Macrotasks.
  • DOM Manipulation, Event Listeners, Form Event Handling.
  • Browser Persistence: LocalStorage, SessionStorage, JSON parsing/stringifying.
  • Debugging using Chrome DevTools, Breakpoints, Network Inspection.
Month 1 Goal:

By the end of Week 4, write functional JavaScript independently without copying code from tutorials.

Phase 1 Capstone Deliverable

✓ Dashboard UI ✓ Customer Management ✓ Product Catalog ✓ Invoicing Engine ✓ Payment Tracker ✓ Dynamic Reports ✓ Search & Filtering ✓ CRUD & Form Validation

React 18 / 19 Foundation & Patterns

Months 2–3 (Weeks 5–12)

Month 2: React Foundation (Weeks 5–8)

Core Component System

  • Props passing, State mechanics, Event handling, Conditional rendering.
  • Keys in lists and reconciliation algorithm mechanics.
  • Form handling, Controlled components vs Uncontrolled components.
  • React Hooks Mastery:
    • useState • useEffect • useRef • useContext • useMemo • useCallback
  • Component composition, Reusable UI components, Custom Hooks creation.
  • API integration patterns: Loading states, Error states, Empty states, Skeleton loaders.
// Custom Hook API Pattern
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  useEffect(() => { /* fetch execution */ }, [url]);
  return { data, loading };
}

Month 3: Professional React (Weeks 9–12)

Enterprise Ecosystem
  • Routing: React Router, Nested layouts, Dynamic routes, Protected routes.
  • State Management: Local state vs Context API vs Server State (TanStack Query / React Query).
  • Forms & Validation: React Hook Form integrated with Zod schema validation.
  • Professional Architecture: Enterprise folder structure, Code splitting, Lazy loading with React.lazy and Suspense.
  • Error Boundaries, Accessibility (a11y), API Integration, Authentication flows, Role-Based Access Control (RBAC).
// Zod Schema Validation
const UserSchema = z.object({
