Part 01

Modern JavaScript Foundations

The core features you will repeatedly meet in React, Next.js, Node.js and modern JavaScript.

01

const, let & Block Scope

Use variables to store values. let can be reassigned; const cannot be reassigned. 

let age = 30;
age = 31; // allowed

const name = "Paul";
// name = "John"; // error

🧠 Remember: let can change. const cannot be reassigned. Both respect block scope.

02. Template Literals

Use backticks and ${...} to place JavaScript expressions directly inside text. 

const name = "Paul";
const age = 31;

console.log(`Hello ${name}, you are ${age}.`);
🧠 Memory: Backticks + ${} = JavaScript inside text.

03. Destructuring Objects

Pull named properties out of an object in one step. 

const user = {
    name: "Paul",
    age: 31,
    country: "Uganda"
};

const { name, age } = user;

console.log(name); // Paul
console.log(age);  // 31
🧠 Memory: { } destructuring = take properties by their names.

04. Destructuring Arrays

Pull values out of an array according to their position. 

const colors = ["red", "green", "blue"];

const [first, second, third] = colors;

console.log(first);  // red
console.log(second); // green
🧠 Memory: Objects use names; arrays use positions.

05. Object Literals & Property Shorthand 

const name = "Paul";
const age = 31;

// Old style
const user1 = { name: name, age: age };

// Modern shorthand
const user2 = { name, age };
🧠 Memory: If the property name and variable name match, write it once.

06. for...of Loop

for...of walks through the values of an iterable such as an array. 

const fruits = ["apple", "banana", "orange"];

for (const fruit of fruits) {
    console.log(fruit);
}
🧠 Memory: OF = values. Think: “for each value of this collection”.

07–08. Spread & Rest Operators

Both use ..., but the meaning depends on where you use them. 

// SPREAD = unpack
const numbers = [1, 2, 3];

const more = [...numbers, 4, 5];

// Object spread
const user = { name: "Paul", age: 31 };
const updated = { ...user, age: 32 };
// REST = collect
function add(...numbers) {
    return numbers.reduce(
        (total, n) => total + n,
        0
    );
}

console.log(add(10, 20, 30));
SPREAD → unpack/open
Take values out and place them somewhere.
REST → collect
Gather remaining arguments into an array.

09. Arrow Functions

// Traditional function
function add(a, b) {
    return a + b;
}

// Arrow function
const add = (a, b) => a + b;
🧠 Memory: => is the visual signature of an arrow function.

10. Default Parameters

function greet(name = "Guest") {
    return `Hello ${name}`;
}

console.log(greet());      // Hello Guest
console.log(greet("Paul")); // Hello Paul
🧠 Memory: Default parameter = backup value.

11. Export & Import

// math.js
export const add = (a, b) => a + b;
// app.js
import { add } from "./math.js";

console.log(add(5, 3));

12. Trailing Commas

const user = {
    name: "Paul",
    age: 31,
};

A comma after the final item is valid in many modern JavaScript structures and can make future edits cleaner.

13. includes()

Ask the simple question: “Is this value inside?” 

const fruits = ["apple", "banana", "orange"];

fruits.includes("banana"); // true
fruits.includes("mango");  // false

"JavaScript".includes("Script"); // true
🧠 Memory: includes() = “Is it inside?”

14. Async & Await

Used when JavaScript works with operations that finish later, such as network requests. 

async function getUsers() {
    const response =
        await fetch("/users");

    const users =
        await response.json();

    return users;
}
Think: ordering food 🍲

↓

↓

🧠 Memory: async = this function can work with waiting; await = wait for this Promise here.

15. Sets

A Set stores unique values. Duplicate values are not stored twice. 

const numbers = new Set([1, 2, 2, 3, 3]);

console.log(numbers); // Set(3) { 1, 2, 3 }

numbers.add(4);
numbers.has(2);    // true
🧠 Memory: SET = unique values.

16. Classes

A class is a blueprint from which objects can be created. 

class User {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        console.log(`Hello ${this.name}`);
    }
}

const user = new User("Paul", 31);
user.greet();

Powerful Everyday Features

Small features with big practical value.

17. padStart() & padEnd()

Add characters until a string reaches a chosen length. 

"5".padStart(3, "0"); // "005"
"5".padEnd(3, "0");   // "500"

18. Exponential Operator **

Raise one number to the power of another. 

2 ** 3;  // 8
5 ** 2;  // 25
10 ** 3; // 1000
🧠 Memory: ** = “to the power of”. Think 2³.

19. Object.values()

Get all the values from an object as an array. 

const user = {
    name: "Paul",
    age: 31,
    country: "Uganda"
};

Object.values(user);
// ["Paul", 31, "Uganda"]
🧠 Memory: VALUES = “give me the values.”

20. Object.entries()

Get each key and value together as pairs. 

const user = {
    name: "Paul",
    age: 31
};

Object.entries(user);

// [
//   ["name", "Paul"],
//   ["age", 31]
// ]
name + Paul = entry
🧠 Memory: ENTRIES = keys + values together.

21. Maps

A Map stores explicit key → value relationships. 

const users = new Map();

users.set(1, "Paul");
users.set(2, "John");

users.get(1);   // "Paul"
users.has(2);   // true
users.delete(1);

SET

Unique values

Paul · John · Mary

MAP

Key → value

1 → Paul
2 → John
3 → Mary

Object.getOwnPropertyDescriptor(user, "name");

Test Yourself Before Looking at the Answers

1. What is the output? 
const numbers = [1, 2, 3];
const newNumbers = [...numbers, 4];
console.log(newNumbers);
2. What does this extract? 
const user = {
    name: "Paul",
    age: 31
};

const { name } = user;
3. Spread or Rest? 
const copy = [...numbers];

function test(...numbers) {}
4. What does entries() return? 
Object.entries({
    name: "Paul",
    age: 31
});
5. Set vs Map?

Explain the difference in one sentence each.

6. What does await mean? 
const result = await fetch("/api/users");
Show answer key

1. [1, 2, 3, 4] — spread copies/unpacks the original array.

2. It extracts the name property from the object.

3. [...numbers] is spread; ...numbers in a parameter list is rest.

4. An array of [key, value] pairs.

5. Set stores unique values; Map stores key/value relationships.

6. It waits for the Promise returned by fetch() to settle before assigning the result.

Mini JavaScript Challenge

Read the code and try to explain every feature before checking the notes. 

class User {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet(message = "Hello") {
        return `${message}, ${this.name}`;
    }
}

const users = [
    new User("Paul", 31),
    new User("John", 28),
    new User("Mary", 25)
];

const names = users.map(({ name }) => name);
const uniqueNames = new Set(names);

for (const name of uniqueNames) {
    console.log(name);
}
class → blueprint
constructor → initializes each object
new → creates an object
default parameter → fallback message
template literal → dynamic greeting
destructuring → gets name from each object
arrow function → compact callback
Set → unique names
for...of → loops over values
this → current User object
